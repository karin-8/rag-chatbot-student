# RAG in Production: Chatbot Workshop

Build a RAG customer-support chatbot the way AI engineers run one in
production: a persistent knowledge base, a versioned prompt, an enforced
policy, a golden dataset with a quality gate, CI/CD and monitoring.
No earlier notebook needed.

| Folder | What it is |
|---|---|
| [`student-guide/`](student-guide/index.html) | The workshop guide: a scenario, tasks and expected results for each module. Download and open `index.html` in your browser. |
| [`rag-chatbot-student/`](rag-chatbot-student/) | The starter project you'll work in. |

## Getting started

1. Click **Code → Download ZIP** and unzip it. Use Download ZIP rather than
   `git clone`: during the workshop you'll turn `rag-chatbot-student/` into
   your own git repository, starting from an empty history.
2. Open `student-guide/index.html` in your browser and complete the
   **Appendix A: Pre-Class Setup** at home. It downloads about 1.1 GB of model
   weights, so do it on a good connection.
3. Bring a laptop (Windows or Mac) to class. A tablet can't run the project.
